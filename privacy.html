Privacy Policy

Last updated: October 8, 2026

Gors Assistant is a private application used only by its owner. It is not available to other people.

What data it accesses

  • Google Calendar: events, read-only.
  • Gmail: messages, read-only. The application cannot send, delete or change email.

How the data is used

  • To show the owner's calendar and recent email in the owner's private dashboard.
  • Sender, subject and date of messages are sent to Anthropic's Claude API to sort them by importance. The text of a single message is sent only when the owner asks for a reply draft.

Storage and sharing

  • Data is kept only on the owner's private server, as a short-lived cache.
  • Data is not sold, not shared with anyone else and not used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
